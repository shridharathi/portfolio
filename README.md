  - [Styled Components](https://styled-components.com/)
- **Deployment:**
  - [Cloudflare Workers](https://developers.cloudflare.com/workers/)
  - [Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/)

## Cloudflare Workers

Build and preview the production bundle through Wrangler:

```bash
npm run dev:worker
```

Deploy the portfolio as a static-assets Worker:

```bash
npm run deploy:worker
```

The deploy command builds the React app into `build/`, then publishes that directory using the configuration in `wrangler.jsonc`.
